# Les Brumes

Éditeur de cartes tactiques 3D pour jeu de rôle.

Ce dépôt est préparé pour un hébergement statique sur Railway avec Caddy. Les fichiers de l'application doivent être importés à la racine, notamment `dist/index.html` et tout le dossier `dist/` (modules, modèles et textures). Le Dockerfile utilise le port fourni par Railway (`PORT`, 8080 par défaut).

Le code de l'application n'est pas encore importé. Ne pas lancer le déploiement avant son import.
